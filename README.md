# Weather App (Java Servlet)

A dynamic weather application that retrieves real-time weather data for any city using the OpenWeatherMap API.

## Features
- Search weather by city name
- Displays temperature, humidity, wind speed, and weather condition
- Real-time API data fetching
- Java Servlet backend processing
- Clean UI with HTML and CSS

## Technologies Used
- Java
- Java Servlets
- JSP
- HTML
- CSS
- OpenWeatherMap API
- Gson (JSON parsing)
- Apache Tomcat

## How It Works
1. The user enters a city name in the form.
2. The request is sent to a Java Servlet.
3. The servlet calls the OpenWeatherMap API.
4. The API returns weather data in JSON format.
5. The application extracts temperature, humidity, wind speed, and weather condition.
6. The results are displayed on the webpage.

## Project Purpose
This project was created to practice:
- Java web development
- Servlet and JSP architecture
- API integration
- JSON parsing using Gson
